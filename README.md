# PROTOTYPE

## Shruti Silk Stories

A luxury handloom saree storefront prototype. The complete project, images, showroom media, and local preview server are in [`shruti-silk-stories/`](./shruti-silk-stories/).

- [Open the website source](./shruti-silk-stories/index.html)
- [Read setup and feature notes](./shruti-silk-stories/README.md)

The storefront includes an animated introduction, timed hero carousel, editorial collection galleries, product rails, interactive product detail, search, wishlist, and a shopping-bag demo. Checkout is not connected to a real payment system.
